# Aashray'sPA — Frontend Command Centre

Private AI-Powered Multi-Account Social Media Command Centre.
Built with Next.js 14, React, TypeScript, and Tailwind CSS.
Visual design: **Apple + Linear + macOS + Premium Glassmorphism**.

---

## Features
- **Single-Owner Authentication**: Private access for Ashray only.
- **Unified Overview Dashboard**: Connected account statuses, volume metrics, approval counts, and live activity feeds.
- **Unified Inbox**: Multi-account conversation threads with AI-drafted replies and single-click copy for personal accounts.
- **Approval Centre**: Safety-first gate allowing review, inline editing, rejection, or one-click approval of AI responses before delivery.
- **AI Assistants Hub**: Independent configuration for all 4 social accounts (tones, prompt instructions, autonomy modes, Hinglish sliders, and bottle advertising knowledge).
- **History & Audit Logs**: Immutable chronological timeline of all incoming and outgoing messages.
- **Analytics & Waveform**: Message volume trends, AI auto-reply rates, and average response times.
- **Connected Accounts**: Health and synchronization status across Instagram Personal, Instagram Business, WhatsApp Personal, and WhatsApp Business.
- **Global Search (`⌘K` / `Ctrl+K`)**: Rapid navigation across conversations, accounts, and system settings.
- **Adaptive Dual-Theme**: Full light and dark themes matching macOS aesthetic.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

Default owner login:
- **Username**: `ashray` (or `satyam`)
- **Password**: `••••••••` (any password $\ge$ 6 characters)

### 3. Production Build
```bash
npm run build
npm start
```
